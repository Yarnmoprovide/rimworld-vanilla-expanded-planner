## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Content Browser** | Browse items and features added across all active VE modules |
| **Faction Planner** | Plan starting faction and biome choices with VE content in mind |
| **Module Tracker** | Track which Vanilla Expanded modules are active in your mod list |
| **Colony Goals** | Set colony goals using VE content and track progress |
